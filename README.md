# Recommendation-system-in-R
# Movie Recommendation System Using R

## Overview

This project implements a movie recommendation system using R.
The system analyzes user ratings and recommends movies based on
similar user preferences.

## Objectives

- Analyze movie rating data
- Perform data cleaning and preprocessing
- Explore user and movie ratings
- Build a recommendation model
- Generate personalized movie recommendations

## Technologies Used

- R
- RStudio
- recommenderlab
- dplyr
- ggplot2
- MovieLens Dataset

## Dataset

The project uses the MovieLens dataset containing movie information
and user ratings.

## Project Workflow

1. Load the dataset
2. Clean and preprocess the data
3. Perform exploratory data analysis
4. Create a user-movie rating matrix
5. Build a collaborative filtering model
6. Generate movie recommendations
7. Evaluate the recommendation system

## Results

The system generates personalized movie recommendations based on
user rating patterns and similar user preferences.

## How to Run

1. Clone this repository.
2. Open `recommendation_system.R` in RStudio.
3. Install the required packages.
4. Place the dataset inside the `data` folder.
5. Run the R script.
